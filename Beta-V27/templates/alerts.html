Create Alert Configuration
FIM Alert Configuration — When enabled, email notifications will be sent for file create, modify, delete, and rename events on the specified agents and paths. The Agent Name and File Path fields are required.
Comma-separated agent names (agent.name) to monitor.
Comma-separated file paths or directories (syscheck.path) to monitor.
Comma-separated file names to monitor only specific files.
Comma-separated extensions to monitor specific file types.
FIM Email Content

Each FIM alert email includes: system info (agent, IP, hostname, OS, user), file info (path, name, extension, size), action details (created/modified/deleted/renamed, timestamp), integrity hashes (MD5, SHA1, SHA256 before & after), user info (account, SID, audit info), and alert metadata (rule ID, severity, alert ID).

Separate multiple addresses with a comma.
Enter time in 24-hour format (HH:MM). Leave empty to send alerts immediately as they occur.
Select fields to include in the CSV export attached to alert emails. Vulnerability and Threat Detection emails automatically include all relevant fields in their dedicated templates.
Common Endpoint & Rule Information
Vulnerability Applies when the alert contains vulnerability data
Threat Detection Applies when the alert contains Windows Defender / threat data
